# 🔐 Gerador de Senhas

## Agrinho 2026

Projeto desenvolvido como atividade educacional, com o objetivo de criar uma aplicação web capaz de gerar senhas personalizadas.

O usuário pode escolher o tamanho da senha e definir quais tipos de caracteres deseja utilizar.

---

## ⚙️ Funcionalidades

* 🔐 Geração automática de senhas;
* 🔢 Escolha do tamanho da senha;
* 🔠 Letras maiúsculas;
* 🔡 Letras minúsculas;
* 🔢 Números;
* 🔣 Símbolos;
* 📋 Copiar a senha para a área de transferência;
* 📱 Layout responsivo;
* 🔴 Interface com tema vermelho.

---

## 💻 Tecnologias

O projeto utiliza:

* HTML5
* CSS3
* JavaScript

---

## 🚀 Como utilizar

1. Abra o arquivo `index.html`.
2. Escolha o tamanho desejado para a senha.
3. Selecione os tipos de caracteres.
4. Clique em **Gerar senha**.
5. Clique em **Copiar** para copiar a senha.
